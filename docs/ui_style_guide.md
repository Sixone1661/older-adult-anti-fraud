# “停一下”界面样式指南

## 设计目标

界面以温暖陪伴、清晰可信、低认知负担和非污名化为原则。视觉参考只用于提取亲切、生活化的气质，不复用参考图中的品牌、文字、医疗能力或页面结构。

## 色彩

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面背景 | `--color-bg` | `#FFF9F1` |
| 卡片背景 | `--color-surface` | `#FFFFFF` |
| 主色 | `--color-primary` | `#F28C52` |
| 标题 | `--color-title` | `#71351F` |
| 辅助蓝 | `--color-blue` | `#4A9FE5` |
| 正确反馈 | `--color-success` | `#397A50` |
| 警示反馈 | `--color-warning` | `#A8472B` |
| 正文 | `--color-text` | `#34302D` |

颜色不单独表达对错：反馈区同时使用标题、正文说明和结构化线索。

## 排版与布局

- 正文默认18px，行高1.68；标题约24–36px。
- 三档字号通过根元素`data-font-size`和`--font-scale`统一控制。
- 页面采用居中单栏，桌面最大宽度960px；390px视口保留至少10px外边距。
- 主按钮与选项最低52px，允许长文字自然换行。
- 卡片圆角8px，使用轻边框和浅阴影；避免多层卡片套叠。
- 训练页顶部使用文字加进度条，进度条仅作辅助，不替代文字。

## 组件

- 主按钮：深橙底、白字，承担当前页面的主要动作。
- 次按钮：白底、橙色边框，用于提示、返回和替代动作。
- 危险操作：默认白底砖红文字，降低视觉权重；仍需二次确认。
- 消息卡：浅暖背景中的白色消息块，左右边线帮助区分信息，但不仿冒具体平台。
- 正确反馈：柔和绿色背景并包含明确文字。
- 风险/提醒：暖橙或砖红边线并包含具体说明。
- 陪练建议：浅蓝背景，标题明确写“陪练建议”，与学习提示分开。

## 插画

首页使用原创`assets/illustrations/hero-elder-family.png`。画面表现中国老年人与成年子女共同查看手机，强调平等陪伴和共同核验；不包含文字、货币、品牌、医疗元素或风险标签。

## 无障碍

- 所有主要动作可用键盘完成，页面切换后焦点回到H1。
- `:focus-visible`使用4px蓝色外框。
- 点击目标不低于48px，主要按钮实际最低52px。
- 尊重`prefers-reduced-motion`，不使用闪烁、轮播、弹跳或持续动画。
- 语音朗读只在用户主动点击后启动，切页时停止。
- 390×844和1440×900均不得出现横向溢出。
