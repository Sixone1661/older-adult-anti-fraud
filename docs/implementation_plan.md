# “停一下”阶段实施计划（冻结版）

## 范围

本轮只实现原生 HTML/CSS/JavaScript 项目骨架，以及欢迎页、角色选择、使用说明、会话恢复/重启确认、三题前测、策略介绍、三步排序、基础状态/路由/localStorage 降级、响应式和键盘焦点。正式训练情境、迁移题、结果计算、防骗卡和所有 P1 功能不在本轮实现。

## 冻结决策

- P0 本地记录页只显示未完成进度、累计完成次数、最近完成时间和清除全部记录。
- companion 只记录角色；内容、流程、计分与 self 相同。
- 前测三题使用已批准题干与 A–D 选项；首次提交计分并锁定，不即时解释，不计最终训练正确率。
- 排序项固定为“停止当前操作 → 通过独立渠道核验 → 无法确认时主动求助”。
- 每个选项显式保存 is_correct、verification_action、help_seeking_action、missed_cues。
- hint_count 只统计主动点击“需要帮助”；本阶段尚无需要帮助入口。
- 计时从选项完整显示到首次提交；后台暂停，返回继续；刷新未提交题时重置；单题上限 300000ms；已提交题刷新不重复写日志。
- 欢迎、角色、说明可返回；前测开始后不回改；全程可回首页并保存进度；重启与清除二次确认。
- currentSession 单独保存路由、题号与阶段状态；最近保留 10 次完成摘要。
- localStorage 不可用或损坏时提示，并以当前标签页内存模式继续。
- session_id 优先 crypto.randomUUID()，否则使用本地随机值。
- 迁移提交后才标记完整会话完成；本轮不实现该节点。

## 文件职责

- index.html：应用壳、跳过链接与脚本入口。
- css/base.css、layout.css、components.css：基础、响应式布局和组件。
- data/content.js、scenarios.js：固定文案与前测数据。
- js/storage.js：持久化探测、损坏降级、日志与摘要。
- js/state.js：会话创建、恢复与状态变更。
- js/router.js：视图切换与标题焦点。
- js/render.js：欢迎、记录、角色、说明、前测、策略视图。
- js/interactions.js：统一事件处理、作答、排序、确认。
- js/app.js：初始化与可见性计时。

## 本轮阶段

1. 文档与内容冻结。
2. 静态 HTML/CSS/JS 骨架。
3. 状态、路由、存储降级和匿名会话。
4. 欢迎、记录、角色、说明、恢复与重启。
5. 三题前测、计时、首次提交锁定。
6. 策略介绍与可键盘操作排序。
7. 390×844、1440×900、键盘、刷新恢复与无持久化 QA。

## 验收

- 可从欢迎页走到排序完成。
- 未完成会话可继续或二次确认后重启。
- 前测已提交答案刷新后仍锁定，日志不重复。
- 页面切换后焦点落到主标题。
- 390×844 无横向滚动；1440×900 内容不过度拉伸。
- 无登录、后端、数据库、AI 或外部平台调用。
