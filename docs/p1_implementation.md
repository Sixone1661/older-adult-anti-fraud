# P1实现说明

## 模块边界

P1前端功能集中在`js/p1.js`，使用独立存储键`stopCheckAsk.p1.settings.v1`。它通过渲染后增强方式加入字号、朗读、图片导出、陪练建议和训练详情，不修改题目、答案、计分、P0会话结构或日志写入规则。

## 已实现功能

- 三档字号：中、大、特大；刷新后恢复，使用根元素`data-font-size`。
- 语音朗读：用户主动启停，朗读当前页面；切页自动停止；API不可用时显示提示。
- 防骗卡PNG：Canvas生成仅含卡片内容的清晰图片，文件名包含日期；失败时提示使用长截图。
- 家人陪练：仅`role=companion`显示“陪练建议”，不计入`hint_count`。
- 训练详情：根据现有匿名日志映射情境和首次选项；缺失数据降级显示，不重复写日志。
- 防骗助手：Streamlit原生页面，服务端调用模型，训练页与结果页仅提供独立入口。

## 测试

`tests/p1-browser.js`覆盖三档字号、双视口、朗读启停、切页停止、PNG、角色隔离、日志详情和控制台。`tests/test_agent_service.py`使用Mock覆盖正常消息、恶意指令文本、敏感信息、缺少密钥、超时和历史上限，不产生API费用。
