# 课程提交说明

## 产品解决的问题

老年学习者在收到催转账、退款、验证码、屏幕共享或高收益投资信息时，可能受到紧迫感、积极诱饵和信息过载影响。“停一下”提供一个安全的模拟环境，让用户在不发生真实转账和信息泄露的情况下练习防骗行动。

## 目标用户

- 具有基本智能手机使用能力的60岁以上学习者；
- 陪伴学习的成年子女、其他家人或社区教育工作者。

本人练习和家人陪练使用相同题目与计分，尊重学习者的自主判断。

## 核心流程

欢迎页 → 角色选择 → 使用说明 → 三题前测 → “停、查、问”策略排序 → 冒充亲属 → 虚假客服 → 虚假投资 → 快递理赔迁移题 → 结果页 → 个人防骗卡 → 本地记录。

核心策略是：

- 停：遇到催促、保密、验证码或高收益承诺时暂停；
- 查：改用自己找到的原号码、官网或官方客服核验；
- 问：无法确认时向可信的人或机构求助。

## 使用的心理学原理

- 社会情绪选择理论与正性偏好：高收益、退款等积极信息可能吸引注意，因此反馈帮助用户重新关注隐藏风险，同时强调“成功保护财产”，避免单纯恐吓。
- 执行功能与有限注意资源：诈骗常制造紧迫感和信息负荷。产品把信息逐步呈现，在决策前设置暂停节点，并让每页聚焦一个主要任务。
- SOC模型：选择典型诈骗情境，通过反复练习优化策略，并用风险线索、独立核验和求助渠道提供补偿性支持。
- 情境学习：用户在接近真实结构但完全虚构的短信、聊天和投资群情境中练习。
- 渐隐支架：情境一提供完整提示，情境二提供主动帮助，情境三弱化提示，迁移题不提供过程提示。

## 预期效果

本原型预期帮助学习者：

- 改善典型风险线索识别；
- 增加暂停、独立核验和主动求助行为；
- 提高防骗自我效能；
- 将“停、查、问”迁移到结构相似的新情境。

## 当前原型不能证明的效果

当前结果只反映一次模拟训练中的选择和行为日志，不能证明：

- 使用者以后一定不会受骗；
- 产品能够准确预测个人真实受骗概率；
- 模拟成绩等同于真实生活行为；
- 产品已经直接降低真实诈骗发生率；
- 结果能够作为医疗、心理或金融诊断。

若要验证真实长期效果，需要后续开展平行情境后测、延迟测验、可用性访谈和规范的研究设计。
