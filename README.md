# “停一下”老年数字防骗情境训练

## 项目简介

“停一下”是面向具有基本智能手机使用能力的 60 岁以上学习者的响应式网页原型。产品通过安全、虚构的数字诈骗情境，帮助学习者练习“停、查、问”：

- 停：遇到催转账、要验证码或要求保密时先暂停；
- 查：通过原号码、官网或官方客服独立核验；
- 问：无法确认时向家人、银行或社区工作人员求助。

本项目是课程作业可点击原型，不收集真实个人信息，也不连接真实支付、消息或诈骗平台。

## 启动方法

项目使用原生 HTML、CSS 和 JavaScript，无需构建或安装依赖。

推荐方式：

1. 直接用最新版 Chrome 或 Edge 打开项目根目录的 `index.html`；
2. 或使用任意静态文件服务器打开项目根目录。

本次验收服务器地址为：

`http://127.0.0.1:4173/`

## 完整功能

- 欢迎页、本人练习和家人陪练角色选择；
- 使用说明与三道前测；
- “停、查、问”策略介绍和三步排序；
- 冒充亲属、虚假客服、虚假投资三个渐隐支架训练情境；
- 无过程提示的快递理赔迁移题；
- 首次提交锁定、逐选项反馈、风险线索和策略回看；
- 正确率、核验、求助、提示、平均决策时间、遗漏线索和复习建议；
- 适合手机长截图的个人防骗卡；
- 未完成进度恢复、最近 10 次完成摘要、累计完成次数和清除记录；
- localStorage 损坏清理与无持久化降级；
- 键盘操作、清晰焦点、390px 手机与 1440px 桌面响应式布局；
- 核心流程离线可运行。

## 数据与隐私

- 数据只保存在当前浏览器的 `localStorage`，不上传服务器；
- 不记录姓名、电话、身份证、银行卡、位置或真实聊天内容；
- 逐题日志使用随机匿名 `session_id`；
- 记录页只展示最近完成摘要，不展示逐题日志；
- 用户可以二次确认后清除当前进度、日志和完成记录；
- localStorage 不可用时，训练仍可在当前页面以内存模式完成，但关闭页面后进度不会保留。

## 当前范围

当前版本已完成 PRD 规定的全部 P0 功能，适合课程展示和可用性测试。

P1的字号、朗读、防骗卡导出、陪练提示、逐题详情和独立防骗助手均已实现。项目仍不包含登录、数据库、云同步、真实支付、风险等级或真实受骗概率预测；模型调用只存在于可选的Streamlit服务端助手模块。

## 已知限制

- 学习记录仅存在于当前浏览器；清理浏览器数据或更换设备后无法恢复；
- 这是教学原型，能够展示模拟任务表现，但不能证明会直接降低真实诈骗发生率；
- 浏览器语音质量取决于操作系统和浏览器已安装的中文语音；
- 防骗助手需要部署者自行配置服务端API密钥。


## 使用 Streamlit 部署到网络

项目根目录包含：

- `streamlit_app.py`：Streamlit 入口，将现有 HTML、CSS 和 JavaScript 内联到组件中；
- `requirements.txt`：云端安装 Streamlit；
- `.streamlit/config.toml`：主题与隐私配置。

部署步骤：

1. 把当前 `main` 分支推送到 GitHub；
2. 登录 [Streamlit Community Cloud](https://share.streamlit.io/)；
3. 选择“Create app”；
4. 选择 GitHub 仓库和 `main` 分支；
5. Main file path 填写 `streamlit_app.py`；
6. 点击部署，等待生成公开网址。

现有前端没有被重写。Streamlit 启动时会读取并内联原始网页资源，因此题目、样式、localStorage 和计分逻辑仍使用同一份源码。

注意：训练记录保存在访问者浏览器中的组件存储空间，不上传至 Streamlit 服务器。若平台更新、重新部署或浏览器限制组件存储，建议重新检查跨会话记录是否仍可保留。

## P1增强功能

- 温暖适老化视觉系统、原创首页陪伴插画和全程文字进度；
- 中、大、特大三档字号，选择保存在独立版本化本地键；
- 用户主动控制的浏览器语音朗读；
- 防骗卡PNG导出与长截图备用说明；
- 仅陪练模式显示的提问建议；
- 基于已有匿名日志的逐题训练详情；
- 独立的Streamlit“防骗助手”，不替代训练流程。

防骗助手是唯一需要服务端和模型API的可选模块。未配置密钥时，全部训练功能仍正常运行，助手页会显示配置说明。复制`.streamlit/secrets.toml.example`并在本地或Streamlit Cloud Secrets中设置`OPENAI_API_KEY`和`OPENAI_MODEL`；真实密钥不得提交。

本地静态训练仍可用`http://127.0.0.1:4173/`访问。要测试防骗助手，需安装`requirements.txt`并运行：

```powershell
streamlit run streamlit_app.py
```

Streamlit更新部署：提交并推送代码后，在Community Cloud应用中选择“Reboot app”；若已连接GitHub，平台通常会自动检测`main`分支更新并重新部署。
